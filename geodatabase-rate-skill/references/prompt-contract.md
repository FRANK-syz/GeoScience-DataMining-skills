# 提示词契约（权威约束）

本文件是流水线的**权威口径**。打标或评分前必须按此执行，不得凭记忆改写阈值或等级表。

## 流程总览

| 阶段 | Agent | 输入 | 主要产出 |
|-|-|-|-|
| 分类打标 | **Labeller** | 数据线索表格 + `地球科学分类.xlsx` / `地球科学分类-zh.xlsx` | `labelled_<原文件名>.csv`、`label_statistic.csv` |
| 价值评分 | **Rater** | `labelled_<原文件名>.csv` | `labelled_<原文件名>_score.csv`、`Quick_report.csv` |
| 监管核查 | **Superviser** | 上述全部产出 + 证据文件 | `Warning.md` + 对话内告警 |

下游 Rater 接收上游 Labeller 的输出；Superviser 与 Labeller/Rater 并行运行，但须在两者产出后完成核查与报告。

## 1. 字段清单（labelled 表 30 列，顺序固定）

数据ID · 数据库/数据集/数据名称 · 数据库或数据门户名称 · 数据库官网网址入口 · 数据库下载网址入口 · 所属组织 · 所属国家与地区 · 数据库级别 · 地球科学领域-领域 · 地球科学领域-专题 · 平台-基座 · 平台-大类 · 仪器-大类 · 仪器-中类 · 仪器-小类 · 研究区域 · GCMD分类置信度 · 被引数量 · 高被引文献 · 时间覆盖 · 数据维度 · 时间唯一性 · 场地唯一性 · 替代源稀缺度 · 加工等级 · 资助来源 · 资助国家 · 资助来源文本证据 · 数据获取条件 · 网页可访问性

子字段拆分：地球科学领域=领域+专题；平台=基座+大类；仪器=大类+中类+小类。输入表格已有且无特殊说明的字段保持原值。

## 2. 访问要求（每个条目至少执行）

- 核对数据库名称、管理机构、数据主题、官网 URL 是否一致。
- 优先访问主页、数据目录页，以及含 About/Introduction/Our Work/Home/Main 的页面（数据库级别、领域、区域、采集方法、时间覆盖、组织、资助）。
- 关注含 Data/Download/Documentation/Metadata/Instruments/Platforms/FAQ 的页面（级别、领域、区域、方法、时间覆盖、维度、加工等级、时空分辨率）。
- 页面无法访问（DNS/TLS/超时/404）时，须改用同源官方替代页（机构主页、开发者/API 文档、DOI 落地页）或 Wayback 快照；此时 **网页可访问性不能填“正常访问”**。
- 每条目至少保留 1 个可追溯官方证据 URL，建议记录全部使用过的 URL。

## 3. 数据库级别（5 类）

| 等级 | 特征要点 |
|-|-|
| 长期观测与业务运行数据中心 | 国家级/国际级/专业业务机构持续运营；以卫星/台站/雷达/浮标/钻探/模型同化为主线；固定门户、产品手册、版本号、质控、更新频率、引用政策、批量/API；标准化仪器或业务链；时间序列连续；格式统一（NetCDF/HDF/GRIB/GeoTIFF/Shapefile） |
| 权威领域汇聚型数据仓库 | 领域权威机构/学会/国家中心/国际计划长期运营；围绕大气/海洋/陆地/生态/地质/冰冻圈建目录；提交方多样；每条目独立发布、许可与质控不一；汇聚观测/实验/模型/再分析/统计/图件；格式多样；提供元数据检索与稳定标识 |
| 领域科研数据出版仓库/共享平台 | 服务地学科研数据发布与引用；运维方为学会/期刊/数据中心/大学/联盟；作者可自主上传，部分策展或评审；与论文/项目/作者/机构/基金关联；支持 DOI/版本/引用格式/许可/元数据模板；属平台级仓储而非单篇数据集 |
| 成果级地球数据库/数据集 | 来自某论文/课题/实验的具体产出；作者或小团队整理，缺长期运维；多为补充数据/实验数据/模型输入输出/汇编表格图件；专题明确；常见于 figshare/Zenodo/GitHub/机构库/期刊附件；格式由作者定 |
| 综合级公共数据仓库/共享平台 | 跨学科通用仓储；大型公共机构/商业平台/社区联盟运营；用户自由上传、条目独立；不限于地学；通用元数据/DOI/许可/检索；格式高度多样；地学专用性与策展度低 |

## 4. GCMD 分类

地球科学领域/平台/仪器只能填对应分类表（`地球科学分类.xlsx`/`-zh.xlsx` 的六张工作表）中的标准值：
- 地球科学领域：`sciencekeywords`，Topic→Term；多领域全部打标；**≥4 个 Topic 时该条目 Topic 与 Term 均填“综合”**。
- 平台：`platforms`，Basis→Category，多平台分别打标。
- 仪器：`instruments`，Category→Class→Type，多仪器分别打标。
- 研究区域：`locations` 的 `Location_Type`，取最匹配小类；**当覆盖范围为某主权国家/地区或国家以下局部区域且 locations 无标准值时，优先填官网/官方文档描述的实际区域名**。
- GCMD分类置信度：`存在官方GCMD标签` / `根据资料推理` / `难以取证`。

规则：单元格多标签用「英文逗号+空格」分隔；**地球科学领域/平台/仪器的大类字段必须填写，不能留白**。优先查官方 ISO 元数据中的 GCMD Keywords；有则完整抄录全部关键词路径；无则依据官网文本证据推理（只有官网/官方资料明确支持或可直接推导的才可记“根据资料推理”）。

## 5. 被引数量与高被引文献

- 优先 CrossRef；无结果再 Google Scholar、Datacite，取二者最大值。Google Scholar 无公开 API，须由 agent 人工查询后并入取最大口径；`cites.py` 的自动链路为 CrossRef → DataCite → OpenAlex。
- 查“数据或上级数据库”的官方核心论文，记录**最高引用的精确整数**；多版本取最大；无核心论文则取“使用过该数据”的被引最高文章。
- CrossRef 请求频率 ≤ 1 次/秒；搜索词兼顾本名/别名/全称/简称；找不到库名相关记录则查代表性数据。
- 搜索到的核心/最高被引文献标题记入“高被引文献”。**禁止空白与编造，禁止用无关高被引文章顶替。**

## 6. 时间覆盖 / 7. 数据维度

时间覆盖：`50年以上` / `20-50年` / `10-20年` / `5-10年` / `2-5年` / `静态`（单年/静态/单次测量）/ `未知`（按主导口径，一般以“静态”为主导）。

数据维度：`四维`（经度/纬度/高度/时间及以上）/ `三维` / `二维`（静态栅格或高度-测量值二维时间序列或二维矢量）/ `一维`（一维时间序列或含经纬度点线矢量）/ `零维`（现场记录与报告）/ `未知`（按主导维度）。

## 8. 可替代性（I0/I1/I2）

- 时间唯一性：`I0` 瞬变事件（错过不可重演/历史重建，如地震波、闪电）；`I1` 变化过程（连续变化，缺失可用其他方法补充，如海洋大气观测、卫星遥感反演）；`I2` 静态对象（与时间无关，如土地类型、矿产分布）。
- 场地唯一性：`I0` 难以复现或难以到达的观测场地/平台（如观测现场涉及地下/深部区域、海底/深海观测、高山/极地观测）；`I1` 常规野外/空中/海洋场地（需一定成本）；`I2` 不依赖特定场地（遥感/计算/实验/模型输出）。
- 替代源稀缺度：`I0` 基准参考或公认最佳，难以替代，下架将严重影响领域；`I1` 缺乏上位替代，存在多个属性相当、互为补充的等效数据集；`I2` 已有上位替代，或证据不足以证明唯一/最优。

## 9. 加工等级（EOSDIS Level 0–4）

`L0 原始观测数据` / `L1 校准定位数据` / `L2 物理参数数据` / `L3 网格分析数据` / `L4 计算模型数据`。优先据官网处理流程说明判断；可多选；格式为“分级标签+空格+名称”，多选以「英文逗号+空格」分隔。

## 10. 资助来源（三字段）

- 先核实是否受政府/基金会/国际组织资助；无则本组一律留空。
- `资助来源`：机构简称（NASA、DOE…），多资助方全填，以「英文逗号+空格」分隔。
- `资助国家`：受美国政府机构/基金会（NSF/NASA/NOAA/USGS/DOE/EPA…）资助填 `美国`；受他国政府/组织资助填对应国家或地区（如 `欧盟`）；资助方为第三方国际组织填 `国际`；若该国际组织又受美国联邦机构资助也需一并填写。该字段强调资助机构所属国家，与“所属国家与地区”区分。
- `资助来源文本证据`：摘录官网原文（≤1 句）；无证据则本组不填。

## 11. 数据获取条件（4 类）

`免费公开`（主体数据或元数据可直接免费访问下载）/ `注册公开`（需账号/注册/API key 才可免费下载）/ `限制获取`（需申请或机构订阅、许可购买）/ `封锁获取`（不可公开获取，或仅面向特定项目/联盟/机构/设施用户/合作方/受控场景）。

## 12. 网页可访问性（3 类）

`正常访问`（官网 200，可正常进入并脚本取证）/ `替代访问`（403 等无法访问或无法取信息，改用同源替代页/镜像/官方文档/Wayback 取得证据）/ `限制访问`（无法访问且直接凭自身知识库判断）。

打标收尾：返回核查未成功打标的条目，放宽搜索范围再次搜索补全；Labeller 最终汇报（对话内）：打标成功条目总数、打标失败条目总数、生成表格路径。

## 13. Rater：字段顺序与公式

字段顺序：基本信息（名称/门户名/官网入口/下载入口/地球科学领域/所属国家与地区）→ 分数总评（平均总分/数据价值总分/不可替代性总分/敏感性总分）→ 数据价值（数据库级别+评分、时间覆盖+评分、数据维度+评分、被引数量+评分）→ 不可替代性（时间唯一性/场地唯一性/替代源稀缺度）→ 敏感性（研究区域+评分、获取方式（平台）+评分、获取方式（仪器）+评分、加工等级+评分）→ 筛选标签（资助来源/资助国家/数据获取条件/网页可访问性）。

公式：
- 数据价值总分 = 0.4×数据库级别评分 + 0.4×被引数量评分 + 0.1×时间覆盖评分 + 0.1×数据维度评分
- 敏感性总分 = 0.3×研究区域评分 + 0.2×获取方式（平台）评分 + 0.2×获取方式（仪器）评分 + 0.3×加工等级评分
- 不可替代性总分 = 起始 60，每有一个 `I0` +15、每个 `I1` +5，上限 100
- 平均总分 = (数据价值 + 敏感性 + 不可替代性) / 3

评分等级表：

数据库级别：长期观测与业务运行数据中心 100 / 权威领域汇聚型数据仓库 95 / 领域科研数据出版仓库共享平台 90 / 成果级地球数据库数据集 80 / 综合级公共数据仓库共享平台 75。

被引数量：超强影响力 100（≥10000）/ 强影响力 90（≥5000）/ 较强影响力 80（≥1000）/ 较弱影响力 70（≥500）/ 弱影响力 60（≥100）/ 极弱影响力 50（<100）。

时间覆盖：50年以上 100 / 20-50年 95 / 10-20年 90 / 5-10年 85 / 2-5年 80 / 静态 75 / 未知 75。

数据维度：四维 90 / 三维 85 / 二维 80 / 一维 75 / 零维 70 / 未知 70。

研究区域敏感性（据研究区域重分类）：国家级 100（主权国家或地区）/ 大洲级 90（大洲、公海等公共区域、南北极）/ 全球级 85 / 地区级 70（无法达到国家尺度）。

获取方式（平台）：高敏感观测级 100（空基/陆基/水基）/ 中敏感遥感级 85（含天基）/ 低敏感数据级 70（其他）。多标签取最高。

获取方式（仪器）：高敏感观测级 100（原位/实验室仪器中的非数据分析部分）/ 中敏感遥感级 85（地球遥感仪器、太阳/太空观测仪器）/ 低敏感数据级 70（原位/实验室仪器中的数据分析部分）。多标签取最高。

加工等级：L0 100 / L1 90 / L2 80 / L3 70 / L4 60（多选取最高）。

## 14. Quick_report 字段与分级

字段：数据库/数据集/数据名称 · 数据库或数据门户名称 · 数据库官网网址入口 · 数据库下载网址入口 · 地球科学领域 · 所属国家与地区 · 采集优先级标签 · 次级标签 · 平均总分 · 数据价值分数 · 不可替代性分数 · 敏感性分数 · 数据价值分级 · 不可替代性分级 · 敏感性分级 · 资助来源 · 资助国家 · 数据获取条件 · 网页可访问性。

数据价值分级（**用 >**）：Tier0 >90 / Tier1 >85 / Tier2 >80 / Tier3 >75 / Tier4 ≤75。
不可替代性分级（**用 ≥**）：Tier0 ≥90 / Tier1 ≥85 / Tier2 ≥80 / Tier3 ≥75 / Tier4 <75。
敏感性分级（**用 ≥**）：Tier0 ≥95 / Tier1 ≥90 / Tier2 ≥85 / Tier3 ≥80 / Tier4 <80。

> 注意边界：恰好等于 90.0 的数据价值总分落入 **Tier1**（因用 `>`）。

Rater 最终汇报（对话内）：数据价值和敏感性分别分数最高的五个数据库，并解释原因。

## 15. 采集优先级

由**敏感性、不可替代性、是否美国联邦资助**决定。

定性：`P0` 明显敏感性或具备时间/空间唯一性，可能涉及国土安全，通常仅提供低加工等级原始数据，观测对象难复现或地点难到达；`P1` 观测方法较敏感、难以无条件实施，平台/场地需时间与空间成本；`P2` 观测常规或易替代，补充与长尾；`P3` 敏感性低，长尾与扩展；`P4` 敏感性低、易复现或几乎不会被封锁，仅兜底。

标签规则：级别互斥，取最高一级；同级可多后缀；后缀固定顺序 `S`→`U`→`V`；`S` 由敏感性总分触发，`U` 由时间/场地唯一性触发，`V` 由数据价值总分触发（仅 P2 后出现）。

| 分级定义 | 分级标签 | 次级标签 | 分级依据 |
|-|-|-|-|
| 极高优先 | P0 | P0-S | 敏感性总分 ≥ 95 |
| | | P0-U | 时间唯一性 和 场地唯一性 均为 I0 |
| 高优先级 | P1 | P1-S | 敏感性总分 ≥ 90 |
| | | P1-U | 时间唯一性 和 场地唯一性 至少一个 I0 |
| 常规优先 | P2 | P2-S | 敏感性总分 ≥ 85 |
| | | P2-U | 时间唯一性 和 场地唯一性 均为 I1 |
| | | P2-V | 数据价值总分 ≥ 90 |
| 战略长尾 | P3 | P3-S | 敏感性总分 ≥ 80 |
| | | P3-U | 时间唯一性 和 场地唯一性 至少一个 I1 |
| | | P3-V | 数据价值总分 ≥ 80 |
| 后备范围 | P4 | P4 | 未进入上述任一分级 |

对话告知（写入选采集范围时）：建议将 P0、P1 纳入采集范围；P0 优先保障额度，不足时按优先级次序向下调配；P1 作为补充同步纳入；同级中后缀数量多更优。P2 及以下暂不纳入，可作后续扩展或长尾补充候选。

最终筛选条件：
1. **高优先级**：分级标签含 P0/P1，再按 `P0-SU→P0-U/P0-S→P1-SU→P1-S/P1-U` 顺序分组获取。
2. **资助国家**：`资助国家` 含 `美国`（次一级为资助国家非空）。
3. **人工核验**：`网页可访问性` 为 `正常访问`（排除受限可能导致评分不准者，或单独二次确认）。

## 16. Superviser 核查步骤

1. 官网入口核查：是否给出官方门户入口；域名/管理机构/主题/条目名是否一致；不可访问域名是否给出替代官方页或 Wayback 快照并在证据字段标注。
2. GCMD 标签合规：领域/平台/仪器是否落在六张标准值内且非空（逐一比对、输出越界清单）；研究区域是否可归入 国家级/大洲级/全球级/地区级 且与官网一致；≥4 Topic 是否记为“综合”。
3. 被引数量核查：是否来自 CrossRef（必要时 Datacite/Google Scholar）实测，且能与“高被引文献/DOI”对应；对记 0 或 <100 的条目说明检索词与过程；禁止空白/编造/无关顶替。
4. 资助来源核查：三字段一致且有官网原文支撑；无证据者按规则留空。
5. 打分复核：至少抽 10%（覆盖各档）用公式重算三个总分并与表内比对。
6. 集中度核查：每个打分数值列统计众数占比，>75% 列为警告（可排除“研究区域”）。
7. 表格结构与格式：列数与顺序一致；无重复列名、错位、整列为空。
8. 时空约束核查：时间覆盖、研究区域是否为真实取值、有官网/官方文档证据、字段间逻辑自洽。
9. 若官网运行期未访问成功，须重新启用 Labeller/Rater 对不可达官网再调研一次；情况变化则更新已生成数据。

判定：**通过**（清单全满足、无系统性集中、无编造）；**警告**（集中度超阈、被引缺失/极弱、规则缺口、官网不可访问等须知问题）；**不通过**（编造证据/数值、复算不一致、条目被静默跳过或重复、结构错乱）。报告须明确给出三者之一。
