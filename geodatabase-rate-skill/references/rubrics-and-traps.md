# 判定口径与已踩坑（经验约定）

这些是过往实践中确立、且会影响判断结果的约定，执行时按此对齐。凡与 `prompt-contract.md` 冲突，以契约为准；本文件只补充契约未显式覆盖或易误判处。

## 编码与格式

- 输入线索 CSV 常为 **GB2312**；所有输出统一 **UTF-8 with BOM（`utf-8-sig`）**。
- 多标签分隔符固定「英文逗号 + 空格」`", "`，不得用裸逗号（复核会报“分隔符异常”）。
- GCMD 数组写**英文标准值**，编译时经 `taxonomy_bundle.json` 映射为中文；映射失败会以 `!!` 前缀暴露（如 `!!XXX`），据此定位越界值。

## 可替代性（I0/I1/I2）判定约定

- **场地唯一性**：
  - 地下/深部区域、海底/深海观测、高山/极地观测 → `I0`。含**地下水监测井**的水文观测库（如 USGS NWIS）、地热井场与岩心储层（GDR、EDX）、海洋/水下装置标定（MHKDR）、高原/极地观测站网均按 `I0`，以保持一致口径。
  - 遥感 / 计算 / 实验 / 模型输出 / 纯编目数据 → `I2`（卫星产品、再分析、重建产品、通用仓储）。
  - 常规野外、普通台站网、空中与近海场地 → `I1`（注意：高山/极地站点按 `I0`，不落 `I1`）。
- **时间唯一性**：瞬变事件（野火、地震波、闪电）→ `I0`；连续变化过程（海洋大气观测、卫星反演）→ `I1`；静态对象（土地类型、矿产分布）→ `I2`。
- 改 `场地唯一性` 会牵动不可替代性总分与优先级后缀；`I0` 与 `I1` 均为加分项且 `I0` 权重更高（各 +15 / +5），务必连带复核下游。

## 字段口径一致性（易漏）

- **数据库级别（综合数据门户特例）**：跨领域导航型门户（聚合多库、多层导航指向不同数据库、门户本身不一定承载数据，典型如 NASA Earthdata、NOAA NCEI）判 `综合数据门户`；该行**只填数据库级别**，其余字段留白，Rater/Superviser 跳过评分与合规检查，行保留不得删除。勿把单领域业务数据中心（如 NCEI 的具体数据集）误升为门户——以“是否聚合多个独立数据库”为准。
- **数据获取条件**：凡实际需登录/注册/API key 的门户（如 AmeriFlux、ARM、FLUXNET、Wind Data Hub、MERRA-2、MODIS、GPM 等）应核为 `注册公开`；仅“可直接下载”才 `免费公开`。逐条比对是否被误填 `免费公开`。
- **研究区域**：locations 无标准值（主权国家或国家以下局部）时填**实际区域名**（如 `美国`/`北美`/`全球`/`全球海洋`），评分时再重分类为 国家级/大洲级/全球级/地区级。
- **网页可访问性**：脚本默认 UA 被 403 时，改用浏览器 UA 复测；可正常取信息则记 `正常访问`（勿一律判“替代访问”）。

## 分级阈值边界（高危）

- **数据价值分级用 `>`**：`>90`→Tier0、`>85`→Tier1、`>80`→Tier2、`>75`→Tier3、`≤75`→Tier4。恰好 90.0 落 **Tier1**。
- **不可替代性/敏感性分级用 `≥`**：不可替代性 `≥90/85/80/75`；敏感性 `≥95/90/85/80`。
- 被引数量等级用 `≥`（`≥10000/5000/1000/500/100`，`<100` 为极弱）。

## 证据与反伪造

- 被引次数必须是 **CrossRef 实测整数**（必要时 Google Scholar/Datacite 取最大）；找不到核心论文则取“使用该数据的最高被引论文”，并在“高被引文献”注明检索词与过程。**禁止估测、约数、空白、无关顶替。**
- 每条目至少 1 个可追溯官方证据 URL，建议记录全部使用过的 URL。
- 官网不可达时：记录失败地址与状态码（404/403/TLS 超时等），改用同源替代页/镜像/Wayback 快照，并把替代地址写入证据字段；可访问性不得填 `正常访问`。

## 常见运行期事实（会随时间变化，需实测核对）

- 机构/域名变更：NREL → National Laboratory of the Rockies（NLR，nlr.gov）；DOE 风能门户 winddatahub.pnnl.gov → wdh.energy.gov；Bioenergy KDF bioenergykdf.net → bioenergykdf.ornl.gov。
- 部分 NASA/NOAA 域名可能 TLS 握手失败（如 gpm.nasa.gov、disc.gsfc.nasa.gov、wcrp-cmip.org 403），需准备官方镜像或 ESGF 门户等替代入口。
- GPM 类条目可保留官方 home_url，同时在证据中记录镜像与 Wayback 快照。

## 监管报告（Warning.md）写法

- 通俗自然语言、按问题分段，**不要表格/JSON**；开头一句总体结论（共几类问题、整体影响）。
- 每段四要素：**问题情况 / 可能影响 / 应对过程 / 置信度与采信建议**。
- 收尾列“核查通过项（无需警告）”与“需要注意的警告与相应修复意见”。
- 总体判定三选一：通过 / 警告 / 不通过，须明确写出。
